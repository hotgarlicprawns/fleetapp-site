And the rest of the cockpit

Small things that add up.

Pinned rules

"Ask before you push." Standing rules live in the system prompt, where compaction cannot rewrite them. Fleet suggests rules from what you typed.

Push to talk

A mic button for Claude Code's voice mode. A terminal cannot send "key held", so Fleet does it for you.

Restart to update

One button that keeps the chat. Each pane resumes its own conversation by id, also after you quit Fleet.

Worktree screens

Each screen gets its own git branch and worktree, so two agents never edit the same files.

Skills panel

Search every skill and plugin command on your Mac and in your project. Click one and its command goes into the pane.

Nothing is lost

Close a screen by mistake and it waits in Recently Closed (⇧⌘T). Open any folder as a screen (⌘O).

Many accounts

Run several Claude and Codex accounts side by side, each with its own limits in the top bar.

Clean copy and clipboard

Copy strips the left margin and trailing spaces. Clipboard history sits in the top bar. Drag in images.

Share, with consent

The Share tab opens a GitHub issue with totals only. You read it first and you press send. Nothing leaves before that.

Before you trust it

What Fleet touches

  • It runs the official claude and codex commands. It does not modify them or read your login tokens.
  • Your usage stays between you and your vendor. Fleet is not in that path.
  • The X-ray runs on your Mac. Nothing is uploaded, and there are no analytics.
  • Fleet itself makes two kinds of network call: a license check after you buy, and a plain request for version.json to see if an update exists. Watch them with Little Snitch if you like.

What it does not do

  • Mac only. No Linux or Windows. Apple Silicon only for now.
  • No remote access from your phone or another machine.
  • If you quit Fleet, its agents stop. Chats resume by id, but a task in progress does not.
  • Codex panes show DONE, not WAITING, and have no per-pane cost.
  • No automatic updates. Fleet tells you when a new version exists, and you download it.
  • Beta, from one developer. Expect bugs and tell me about them.

Questions

Does it work with my Claude plan?

Yes. It runs Claude Code in your own account, the same as a terminal. You sign in through Claude Code, not through Fleet.

Why not tmux or plain terminal tabs?

If those work for you, keep them. Fleet is for when you run enough agents that finding the one waiting for you has become the job.

Will it save me tokens?

We do not promise that. See the table above. The X-ray can show you where your usage goes, and what you change is up to you.

Is this made by Anthropic or OpenAI?

No. Fleet is an independent app and is not affiliated with or endorsed by either company. Claude Code and Codex belong to their owners.
