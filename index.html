Fleet shows which agent needs you

Each pane shows WAITING, DONE or working, with its cost and context, read from Claude Code's own hooks. A sound, a Dock count and ⌘J take you to the next one.

Worktree screens
Each screen gets its own branch and worktree, so two agents never edit one file.
Smart compact
Compacts after a chat finishes and waits for you, never mid tool loop. Opt-in.
Chats come back
Each pane resumes its own conversation by id, also after you quit Fleet.
Skills panel
Search every skill and plugin command and send one to the pane.
Many panes, flat memory
In our test, 36 panes streaming heavy output kept Fleet under 400 MB, and its use fell after the first burst. Each agent's own process is extra.

    See what each agent changed, and what it left on disk

    Fleet shows the files each agent touched, opens its folder in your editor, and finds old worktrees and caches that can go to the Trash.

    Files panel
    The pane's folder as a tree. Files the agent changed carry a dot, with a diff and a Quick Look preview. Read only.
    Open in editor
    One click opens the pane's folder in VS Code, Cursor, Zed, Xcode or Finder.
    Disk map
    Sizes of agent worktrees, build folders and Claude Code caches. A dry run comes first, and items go to the Trash. Transcripts and worktrees with unsaved work are never offered.
    One-click updates
    Fleet installs a new version and restarts. Each pane resumes its own chat.

    Install and questions

    READYFleet 1.0.2 · notarized by Apple

    Download Fleet 1.0.2

    Fleet is signed, notarized by Apple and passes 284 automated checks. It needs macOS 13 or later on Apple Silicon. Open the DMG and drag Fleet to Applications.

    Download the DMG, 5.4 MB
    Or install from the terminal

    It downloads the app, checks its SHA-256 and puts it in Applications. Read the script first.

    $curl -fsSL https://fleetapp.in/install.sh | sh

    Or take the DMG from the latest release.

    Does it work with my Claude plan?

    Yes. It runs Claude Code in your own account, the same as a terminal. You sign in through Claude Code, not through Fleet.

    Why not tmux or terminal tabs?

    If those work for you, keep them. Fleet is for when you run enough agents that finding the one waiting for you has become the job.

    Will it save me tokens?

    We do not promise that. See the test table. The X-ray shows where your usage goes, and what you change is up to you.

    What does Fleet not do yet?
    • It runs on Mac only, Apple Silicon only for now. No Linux or Windows.
    • No remote access from your phone or another machine.
    • If you quit Fleet, its agents stop. Chats resume by id; a task in progress does not.
    • Codex panes show DONE, not WAITING, and have no per-pane cost.
    • Updates install with one click, but Fleet never installs one on its own.
    • It is a beta from one developer. Expect bugs and tell me about them.
    Is this made by Anthropic or OpenAI?

    No. Fleet is an independent app and is not affiliated with or endorsed by either company. Claude Code and Codex belong to their owners.
